# ASO Metadata

This ASO set is optimized for `English (U.S.)` and `search-led discovery` first. It favors long-tail intent over broad browsing traffic.

## 1. Core Positioning

- Audience: `landlords`, `small property managers`, `Airbnb hosts`, `tenants`
- Search intent:
  - `rental inspection`
  - `move-in checklist`
  - `move-out report`
  - `property inspection report`
  - `security deposit`
- Value prop:
  - `one-time purchase`
  - `photos + notes + signatures`
  - `PDF report`

## 2. App Name

- Value: `Rental-Report`
- Length: `13 / 30`

Why this works:

- includes the highest-intent head term: `Rental`
- includes the conversion-oriented utility term: `Report`
- keeps the required `xxx-xxx` format
- leaves subtitle room to add `inspection` and `checklist`

## 3. Subtitle

- Value: `Move-In Inspection Checklist`
- Length: `28 / 30`

Why this works:

- directly covers `move-in`, `inspection`, and `checklist`
- complements the title without repeating `rental` or `report`
- matches the way users describe the problem in current App Store listings

## 4. Keywords

- Value: `landlord,tenant,property,deposit,walkthrough,photos,signature,pdf,damage,apartment,moveout`
- Length: `93 / 100`

Notes:

- avoids repeating `rental`, `report`, `move-in`, `inspection`, and `checklist`
- favors high-intent action and dispute words over vague words like `organizer`
- keeps room for later tests if App Store Connect character counting differs by encoding

## 5. Promotional Text

- Value: `Create room-by-room rental inspection reports with photos, notes, signatures, and a shareable PDF. No account. No subscription. Built for fast walkthroughs.`

Use:

- strong enough for launch
- easy to swap later for seasonal landlord or move-out messaging

## 6. Description

### Recommended EN-US Description

`Rental-Report` helps you document the condition of a rental property before move-in, after move-out, or during routine inspections.

Create a clear room-by-room report with photos, notes, signatures, and a polished PDF you can save or share.

Built for independent landlords, small property managers, Airbnb hosts, and tenants, Rental-Report keeps the inspection process simple and fast. No account setup. No subscription. No bloated property management workflow.

What you can do:

- Start a move-in, move-out, or routine rental inspection
- Walk through the property room by room
- Add photos and short notes for every room
- Flag damage, wear, missing items, or cleaning issues
- Capture signatures on the device
- Export a professional PDF report
- Save completed reports for future reference
- Duplicate a move-in report into a move-out inspection draft

Why people use Rental-Report:

- Protect security deposit records
- Keep cleaner landlord and tenant handoff documentation
- Replace paper checklists and scattered camera-roll photos
- Finish inspections faster on site
- Keep evidence organized in one place

Built for practical field use:

- No account required
- No subscription required
- Simple step-by-step flow
- Designed for iPhone

Rental-Report is a documentation tool. It helps you organize property condition records, but it does not provide legal advice.

## 10. Search Strategy

- Win long-tail search instead of generic property traffic.
- Put head terms into `name + subtitle`.
- Use keywords to capture adjacent buyer and dispute language.
- Keep description aligned with visible screenshots so conversion does not collapse after discovery.

## 11. Metadata Test Queue

If initial conversion is weak, test these subtitle variants first:

- `Move-Out Report & Checklist`
- `Property Inspection PDF`
- `Landlord Move-In Checklist`

If ranking is weak, test these keyword replacements:

- swap `apartment` for `check in`
- swap `damage` for `security`
- swap `walkthrough` for `inventory`
